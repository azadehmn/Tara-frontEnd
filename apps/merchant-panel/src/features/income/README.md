# درآمد (Income Chart)

چارت مقایسهٔ درآمد دورهٔ جاری با دورهٔ قبل. روی داشبورد (`HomePage`) با `IncomeChartCard` نشان داده می‌شود.

بالای کارت سوییچ **ماهانه / هفتگی** است. پیش‌فرض ماهانه است.

## داده از کجا می‌آید؟

بک‌اند تاریخ را **میلادی** می‌فرستد. معنی ماه و هفته **شمسی** است.

مثال برای امروز `2026-09-15` (۲۴ شهریور):

| | معنی | from → to (میلادی) |
| --- | --- | --- |
| ماهانه، جاری | ۱ شهریور تا امروز | `2026-08-23` → `2026-09-15` |
| ماهانه، قبل | کل مرداد | `2026-07-23` → `2026-08-22` |
| هفتگی، جاری | شنبه این هفته تا امروز | `2026-09-12` → `2026-09-15` |
| هفتگی، قبل | کل هفتهٔ قبل (شنبه تا جمعه) | `2026-09-05` → `2026-09-11` |

درخواست:

`GET /club/api/dashboard/income-chart?period=MONTHLY` یا `WEEKLY`

فعلاً اگر در `.env.development` این باشد، جواب از ماک می‌آید نه API:

```
VITE_INCOME_CHART_USE_MOCK=true
```

در production این مقدار `false` است. برای وصل شدن به API واقعی همان را `false` کن؛ کد را عوض نکن.

## فایل‌ها به زبان ساده

```
features/income/
├── api/           گرفتن داده + ماک + تبدیل پاسخ
├── model/         شکل داده
├── composables/   منطق، جدا از ظاهر کارت
├── lib/           تاریخ شمسی و فرمت نمایش
├── config/        فلگ ماک از env
└── ui/            فقط کارت و چارت
```

- `useIncomeChart` → داده خام (`current` / `previous`) و سوییچ دوره
- `useIncomeChartSeries` → داده را برای ApexCharts آماده می‌کند (رنگ، محور، تولتیپ)
- `to-income-chart-plot` → نقاط ماه را روی روز ۱ تا ۳۱ شمسی، هفته را روی شنبه تا جمعه می‌چیند. روزهایی که هنوز نیامده‌اند خالی می‌مانند.
- `IncomeChartCard` → ظاهر؛ mapping داخلش نیست

روی UI بازهٔ تاریخ با locale ساخته می‌شود (فارسی: `۱ شهریور تا ۲۴ شهریور`، انگلیسی بدون کلمهٔ فارسی).

رنگ سری‌ها از دیزاین‌سیستم است: `color.chart.current` و `color.chart.previous`.
